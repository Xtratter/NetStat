# NetStat

[English](README.md)

[Скачать APK для Android (v0.1.0 debug)](https://github.com/Xtratter/NetStat/releases/download/v0.1.0/NetStat-0.1.0-debug.apk)

NetStat показывает историю расхода по приложениям в Wi-Fi и мобильной сети.
Для первой сборки нужен Android 10 (API 29) или новее. Достаточно разрешить доступ
к статистике использования в системных настройках.

1. Откройте NetStat и разрешите доступ к статистике.
2. Выберите **Сегодня**, **Прошлая ночь** или свой период, затем Wi-Fi или мобильную сеть.
   В мобильной сети учитываются все подписки, по которым Android вернул данные текущего пользователя.
3. Сравните объём приёма и передачи. Приложения с общим UID показаны в одной строке.
   Для системных категорий и пакетов, которые уже нельзя определить, сохраняется
   название категории или числовой UID.

**Прошлая ночь** — последний завершившийся период с 00:00 до 07:00 местного времени.
До 07:00 это интервал предыдущего дня. После смены часового пояса свой период
сохраняет выбранные моменты начала и конца. При переводе часов назад доступны
оба вхождения повторяющегося местного времени.

Android хранит статистику крупными интервалами и может обновлять их с задержкой.
NetStat складывает целые интервалы внутри выбранного периода, показывает их размеры,
границы и пробелы. Общее покрытие объединяет интервалы разных приложений. У каждого
приложения показано собственное покрытие. Пустая история означает, что Android
не вернул подходящих интервалов. Ноль отображается, когда интервал есть и в нём
учтено ноль байт.

## Сборка и проверка

Нужны JDK 17, Android SDK 35 и Build Tools 35.0.0. Зафиксированы Gradle 8.10.2,
Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Compose Material 3 1.3.1 и Activity Compose
1.10.1. Compose включает готовую нативную библиотеку
`androidx.graphics:graphics-path:1.0.1` по лицензии Apache 2.0. Для сборки
достаточно Android SDK. [Сведения о зависимости](fixtures/README.md).

```sh
./gradlew clean testDebugUnitTest lintDebug assembleDebug
```

APK находится в `app/build/outputs/apk/debug/app-debug.apk`. В Termux Gradle нужен
ARM64-вариант `aapt2` из пакетов Termux. Укажите путь к исполняемому файлу в локальном
параметре Gradle `android.aapt2FromMavenOverride`.

Для проверки на Android 16 разрешите доступ к статистике и сделайте контрольную
загрузку по каждой сети. После обновления счётчиков сравните порядок приложений
и объём байтов с системным экраном за сопоставимый период с учётом покрытия.
Отзовите разрешение и проверьте, что история скрыта. Проверьте границы местных
периодов в полночь и в 07:00, затем смените часовой пояс и повторите проверку.
