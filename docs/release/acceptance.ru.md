# Приёмка NetStat на Android

Записывайте модель телефона, версию Android, версию NetStat, тип сети и
результат каждого проверенного шага. Для тестового захвата используйте
контрольный клиент и собственный сервер или синтетические данные.

| Проверка | Ожидаемый результат |
| --- | --- |
| Чистая установка на отдельный профиль, тестовый телефон или эмулятор | APK открывается, экран истории показывает состояние доступа. |
| Отказ и отзыв доступа к статистике | Приложение показывает запрос доступа и скрывает недоступные данные. После выдачи доступ восстанавливается. |
| День и ночь | Контрольная загрузка появляется в расходе нужного приложения по соответствующей сети, когда обновится история Android. Сверяются только одинаковые периоды, отдельно приём и передача. |
| Root и VPN | Запустите каждый доступный режим, выберите контрольное приложение, сделайте DNS-запрос и откройте страницу. После остановки проверьте UID, адрес, порты, пакеты и экспорт PCAPNG. Если Android вернул неизвестный UID, он так и должен отображаться. |
| Отказ и отзыв VPN | После отказа системному запросу запись не начинается. Во время записи отзыв VPN в настройках завершает сеанс. После остановки открывается контрольная страница через обычную сеть. |
| Смена Wi-Fi на мобильную сеть | Начните VPN-запись по Wi-Fi и отключите Wi-Fi. NetStat завершает запись при потере исходной сети и сохраняет доступные пакеты. Повторный старт работает через мобильную сеть. |
| Проверка обновления | Сохраните короткую тестовую запись в предыдущей версии. Установите новый APK поверх неё и откройте ту же запись. Сверьте число пакетов и поля соединения. |
| 30 минут с выключенным экраном | Выберите **До 30 мин** и запустите контрольный трафик малой интенсивности. Если файл меньше 8 МиБ, после включения экрана должна быть доступна запись с завершением по времени. |
| HTTPS | Для клиента, настроенного на диагностический прокси, контрольный ответ виден и находится поиском. [Инструкция](../capture/https.ru.md). |

## Сравнение расхода

Проведите два 30-минутных прогона при одинаковой сети и уровне сигнала, с
выключенным экраном и без зарядки. Подайте одну и ту же небольшую нагрузку,
например, контрольную загрузку раз в 30 секунд из одного приложения.
Сначала прогоните её без захвата, затем с захватом. Запишите изменение заряда
или показания счётчика заряда, переданные байты и размер экспортированного
PCAPNG. Если запись завершилась по лимиту 8 МиБ раньше, уменьшите одинаковую
нагрузку в обоих прогонах. Фиксируйте фактическую длительность и отдельно
отмечайте остановку по лимиту. Сравнения Wi-Fi и мобильной сети проводят
отдельно.

## Проверка APK

GitHub Actions запускает JVM-тесты, Python-тесты, lint и сборку. Артефакт
Actions подписан временным отладочным ключом запуска. Для обновления ставьте
APK из GitHub Releases. Скачайте APK и `SHA256SUMS.txt` из одного релиза в
одну папку и проверьте контрольную сумму.

```sh
sha256sum -c SHA256SUMS.txt
```
